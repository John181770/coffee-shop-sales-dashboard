# ☕ Coffee Shop Sales Dashboard

> An interactive Power BI dashboard providing actionable insights into coffee shop sales performance, customer behavior, and operational metrics.

## 📊 Project Overview

This project demonstrates business intelligence and data visualization skills by building a comprehensive sales dashboard for a coffee shop. The dashboard transforms raw transaction data into interactive visualizations that enable data-driven decision-making for store managers and business analysts.

**Status:** ✅ Complete  
**Tech Stack:** Power BI, CSV Data  
**Dataset:** Coffee Shop Sales (CSV)

---

## 🎯 Key Features

### Sales Performance Metrics
- **Total Revenue & Units Sold** - High-level KPIs for quick business health assessment
- **Revenue Trends** - Month-over-month sales performance visualization
- **Sales by Category** - Product category breakdown (Coffee, Tea, Bakery, etc.)

### Customer & Operational Insights
- **Hourly Sales Distribution** - Identify peak and off-peak hours for staffing optimization
- **Location Performance** - Compare revenue and footfall across store locations
- **Product Analysis** - Top-performing products and slow-moving inventory
- **Weekday Patterns** - Customer traffic and order patterns by day of week

### Interactive Filtering
- **Date Slicers** - Filter by specific time periods for focused analysis
- **Store Location Filter** - Drill down into individual store performance
- **Category Segmentation** - Analyze specific product categories

## 🚀 How to Use

### Prerequisites
- **Power BI Desktop** (free version available at [powerbi.microsoft.com](https://powerbi.microsoft.com))

### Steps
1. **Download the PBIX file**  
   Clone/download this repository and locate `Coffee Shop Sales.pbix`

2. **Open in Power BI Desktop**  
   - Launch Power BI Desktop
   - Select "Open" and navigate to the `.pbix` file
   - Click "Open"

3. **Explore the Dashboard**  
   - Use slicers to filter by date range, location, or category
   - Hover over visuals for drill-down details
   - Export reports or raw data as needed

4. **Update with New Data** (Optional)
   - Replace the CSV file with updated sales data
   - Refresh data connections in Power BI
   - Dashboard automatically updates with new metrics
